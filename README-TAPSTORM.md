# TAPSTORM

TAPSTORM v0.4.0 adds an installed-app picker to the colorful Android interval reminder.

- Add / Change App lists launchable apps installed on the phone and saves the selected app locally.
- Open App launches the selected app.
- Remove Selected App clears the saved selection.
- Quick intervals: 5, 10, 15, 30, 60 seconds; custom interval: 5 to 3,600 seconds.
- Start/Stop controls, visible countdown, vibration and reminder toast.
- Selecting an app is a local launcher shortcut only; it does not grant control over that app or press its buttons.
- The user must manually tap Search in Airtel Merchant. No Accessibility service, cross-app screen reading, auto-clicking, payment access, or background automation is included.
- Timer runs only while TAPSTORM remains open.
