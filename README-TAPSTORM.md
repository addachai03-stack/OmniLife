# TAPSTORM

TAPSTORM v0.3.0 is a colorful Android interval reminder for Airtel Merchant refresh workflow.

- Quick intervals: 5, 10, 15, 30, 60 seconds.
- Custom interval: 5 to 3,600 seconds.
- Start/Stop controls, visible countdown, vibration and reminder toast.
- When the interval ends, the user manually taps Search in Airtel Merchant.
- Runs only while TAPSTORM remains open.
- No Accessibility service, cross-app screen reading, auto-clicking, payment access, or background automation.
