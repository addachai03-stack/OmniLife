# TAPSTORM

TAPSTORM is a simple Android interval timer.

## Android app
- User chooses an interval from 10 to 3,600 seconds.
- Start and Stop controls operate a visible countdown in TAPSTORM.
- The timer runs only while TAPSTORM remains open.
- It does not access, inspect, click, or control other apps.
- It requests no Accessibility permission and includes no automation service.
- It does not interact with payments, UPI, transfers, deposits, withdrawals, approvals, OTPs, PINs, or credentials.

## iPhone-friendly PWA
The PWA is a timer-only experience. iOS PWAs cannot control other iPhone apps.

## Build
The Android debug APK is built by the repository's GitHub Actions workflow. This is a timer utility, not an auto-clicker.
